# 🎓 EduTrack – Student Tracking & Mentor Management System

EduTrack is a web-based student management application developed using **Python and Streamlit**. It helps mentors manage student records, search and update information, register new students, and maintain student databases efficiently.

## ✨ Features
- 🔐 Mentor Login & Authentication
- 📊 Student Dashboard
- 📁 Upload Excel and CSV databases
- 🔍 Search students by ID or Name
- ✏️ Edit and update student records
- ➕ Register new students
- 💾 Save student data in Excel files
- 📋 Manage student status and mentor remarks

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- OpenPyXL

## ⚙️ How to Run

1. Install dependencies:

   ```bash
   pip install streamlit pandas openpyxl
   ```

2. Run the application:

   ```bash
   streamlit run app.py
   ```

3. Open the application in your browser.
